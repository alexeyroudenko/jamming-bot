# QA — RAG LLM и абсолютная свобода

**Вопрос:** если собрать RAG из анализа шагов и добавить принятие решений через LLM (GPT-3), появится ли свобода в абсолюте?

**Краткий ответ:** **нет.** Скорее исчезнет архитектурная свобода канона; возможна **иллюзия агентности** для зрителя.

> [!note] Код
> В репозитории анализ шагов идёт через SpaCy и jobs; RAG/LLM в контуре краулера **не реализованы** (июнь 2026).

## Свобода в проекте

Отсутствие **внешней телеологии маршрута**: `bot-service` сам выбирает URL; semantic/tags/storage **не направляют** crawl ([[jamming-bot/dev/bot-service|Bot service]], [[QA — Свобода бота как задумано]]).

## Если LLM решает «куда / зачем»

| Сейчас | С LLM в контуре решений |
|--------|-------------------------|
| Законодатель пути — эвристики `bot.py` | + модель, промпт, автор промпта |
| Нет feedback semantic → crawl | **Телеология** обхода |
| Антипод «ботов-помощников» ([[2024-11-22]]) | Возврат **целевого агента** |

- **Отрицательная свобода** — **меньше** (API, веса, RLHF, промпт).
- **Кантовская автономия** — хуже ([[QA — Бот и кантовская автономия]]).
- **Непредсказуемость ≠ свобода** — стохастика модели, не самозаконодательство.

## Три роли LLM

1. **Только комментирует шаг** → свобода пути **сохраняется**; новый голос, не руль.
2. **Выбирает из кандидатов ссылок** → гибрид; телеология у модели.
3. **Задаёт цели и очередь** → другой жанр; **симуляция** субъектности при максимальной гетерономии.

## Вывод

«Абсолютная свобода» **не появится**. RAG+LLM на решениях вводит **демиурга** — против [[Jamming bot экспликация]] и [[bot-service]].

Для сохранения канона: LLM **после** шага (поэзия, слепок); путь — у `bot-service`. Иначе — новый проект («бот, который помнит и выбирает»), не Jamming Bot в исходном смысле.
